QUIET PAPER TREATMENT · SAME SIMPLIFIED APP
Four screens, one table of data.
Everything the app knows is one row per day: a number from one to five, up to three optional tags, a date, and a ZIP. The week chart, the map and the paywall are all views of that one table.
TYPE
Newsreader at light weight for anything that speaks to the teacher; IBM Plex Mono, uppercase and tracked out, for labels; system sans for interface text.
COLOR
Warm off-white ground, white cards, one teal accent for anything interactive. The five-step mood ramp is the only other color and it carries meaning everywhere it appears — bars, tiles, map.
VERSIONS
This is v3. v2 is the same app in the Classical serif-and-gold treatment; the fuller system with reminders is in the first file.
